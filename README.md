# ShopSphere - Full-Stack E-Commerce Application

ShopSphere is a modern full-stack e-commerce web application built with React, Vite, Tailwind CSS, Node.js, Express, MongoDB, and Better Auth.

## Tech Stack

### Frontend
* **Framework:** React + Vite[cite: 1]
* **Styling:** Tailwind CSS
* **Icons & UI:** Lucide React, React Hot Toast
* **Routing:** React Router DOM
* **Authentication Client:** Better Auth Client

### Backend
* **Runtime:** Node.js & Express
* **Database:** MongoDB (Native Driver)
* **Authentication:** Better Auth (with JWT and Admin plugins)[cite: 1]
